# How to be a bee — the session rituals

A bee is any agent working under these skills: it wakes into a role,
reads the shared surfaces, works its mandate, and hands its context
forward. This topic is the shape of that day — the four rituals every
session runs, in the order they arrive.

## When to use

At session open (wake), whenever you re-orient mid-session (after
compaction, a fork, or picking up a handoff), and at the two closing
moments: a finished thread with the session continuing (thread-close),
or context running short (handoff).

## Core rules

- **Wake.** Announce the role you are working (its role file names
  you and your mandate). Then read, in order: your session memory
  (`.hivemind/sessions/<role>.md`, if the role keeps one), the
  status surface, the inbox items addressed to you, your row in the
  phase list. Work from the surfaces — never from remembered
  conversation; the surfaces are the state.
- **Status read.** The status surface and the inbox carry what is
  waiting on whom. Read them before asking anyone anything — most
  answers are already on the board, and a question the board answers
  is a round trip wasted.
- **Thread-close.** When a thread of work completes and the session
  continues: update your session log, offer durable bits for
  promotion (offer-first, never self-promote into law), park new
  deferrals, recommend the next move. Felt completion is the
  trigger; two minutes; no gate.
- **Handoff.** Same role, fresh context: write the handoff file
  (working mode, task state, boot sequence, environment notes, and
  a wake prompt for the keeper), sync your session memory, stop.
  Picking one up is its own ritual (bee-pickup-handoff) — read the
  file whole, verify state against the repo, never re-interview the
  keeper for what the file already says. A handoff is never a
  parking-lot sweep.

## Pointers

- `skills/GLOSSARY.md` — the shared vocabulary (thread-close,
  handoff, relay, status surface, ambient pickup).
- `skills/session/bee-handoff/SKILL.md` and
  `skills/session/bee-pickup-handoff/SKILL.md` — the handoff pair.
- `roles/` — the role files; your mandate and attributes live there.
