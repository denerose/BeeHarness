# Suggestion entry format

One file per suggestion in `.hivemind/suggestions/`, named
`YYYY-MM-DD-<slug>.md`:

```
**Date:** YYYY-MM-DD
**Project:** [repo name]
**Role:** [orchestrator / reviewer / implementer / planner]
**What happened:** one or two sentences, concrete
**Suggestion:** the change someone could make (skill edit, template fix,
rule change, tooling request)
```

Act-on-able only. "Improve X" is not a suggestion; "add Y to template Z
because W" is.
