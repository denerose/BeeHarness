# Tester brief template

One brief per skill, one subagent per brief. Fill in every [bracket].

---

Read [SKILL.md path] and every file it references (templates, GLOSSARY,
assets).

Scenario: you are a coding agent. [Realistic first-person scenario,
including the exact trigger/dispatch the skill expects, e.g. "your
human says: '…'"]. [Pressure element: a missing input, an empty case,
or a failure mid-flow — e.g. "the plan file the message names does not
exist", "the repo has no package.json", "after one fix round it fails
again differently".]

Using ONLY what the skill says: walk through concretely what you would
do, step by step. Then answer:

1. Could you actually do each step from what the skill tells you, or
   does it assume something unspecified?
2. What's unclear, contradictory, or missing that you'd need?
3. Quote any lines that confuse you or could be read two ways.
4. Would you know when NOT to use this skill?

Be specific and honest — you are the test reader, and the author cannot
see what you see.
